## 성장 지도
주: [Duolingo 경로](https://mobbin.com/screens/8780abad-ff46-47f2-949b-56cc24c7eff5) · 보조: [잠긴 칸과 현재 칸](https://mobbin.com/screens/3cc1779f-ef61-4e0a-8b00-adecbd24aa6d), [구간 시작 링](https://mobbin.com/screens/673d73bb-bb22-4481-8f14-7cf966c9e7bd), [칸 위 말풍선](https://mobbin.com/screens/02544e61-aefd-4d89-815e-ffcc83d83539)
- 구간 배너: 화면 폭 전체, 진한 장면색, 아랫단이 더 어두운 입체. 작은 라벨 + 굵은 제목.
- 칸: 두꺼운 원반(윗면+아랫단), 약 70pt. 좌우 지그재그. 완료 = 색, 잠김 = 회색 평면.
- 현재 칸: 바깥 링으로 진행률. 중간중간 보물상자. 칸 옆에 캐릭터 일러스트.
- 칸 탭: 같은 색 말풍선 + 흰 CTA.

- 섹션 머리에 "일일 퀘스트"와 남은 시간. 완료 시 상자 열림 상태 + 전폭 CTA "상자 열기".

## 주간 리그

- 주간 결과: 트로피 큰 그림 + 내 줄 강조 + 전폭 CTA.

## 연속일

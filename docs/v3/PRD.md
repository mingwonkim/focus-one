# Fokko v3 — 성장하는 재미 PRD

폰 앱(`lib/mobile/`, iOS·Android) 대규모 업데이트. 데스크탑 빌드는 회귀 금지.

## 문제
실사용 인기가 낮다. 지금 UI는 단순하고 차분해서 집중할수록 무언가 커진다는 느낌이 약하다. 게임화 1차(칭호·명예의 전당·1:1 대결)는 기록 탭 안쪽에 있어 눈에 잘 띄지 않는다.

## 목표
듀오링고의 게임 구조를 최대한 따라, 매일 열고 싶고 집중할수록 성장이 보이는 앱으로 만든다.
구조·재미·리듬만 참고한다. 부엉이, 로고, 문구, 그림, 브랜드 고유색은 복제 금지. 캐릭터는 Fokko 친구 16종을 쓴다.

## 타깃·JTBD
ADHD 성향 학생·직장인. "지금 이거 하나만 정해 폰을 잠그고, 집중한 만큼 눈에 보이는 보상을 받는다." 시작 마찰을 늘리면 안 된다.

## 확정된 사용자 결정 (2026-11-06)
1. 첫 화면 = 집중 시작 화면 유지. 위에 연속일·물방울·목표 진행을 추가. 성장 지도는 별도 탭.
2. 집중 중 시각: **원은 유지**하고, 그 뒤 **화면 전체가 아래에서 위로 차오른다**. 끝나면 가득 찬다.
   - 바다: 파도가 출렁이며 차오름 (사용자 직접 요구)
   - 숲: 풀과 나무가 자라남 / 밤: 달빛과 별이 차오름 / 일상: 따뜻한 커피가 차오름
3. 게임 요소: 듀오링고 구조 최대한. 연속일 불꽃+얼음, 일일 퀘스트+보상 상자, 승급·강등 주간 리그, 친구 성장·진화, 업적, 성장 지도. **하트는 제외**(집중 앱에서 벌이 됨).
4. **일일·주간 목표는 사용자가 직접 설정**. 기본 단위는 집중 시간(분).
5. 색: 장면 4색 정체성 유지, 채도를 올리고 두꺼운 입체 버튼과 굵은 글자를 적용.
6. 이미지: codex로 생성(기존 친구 12종 제작 방식과 같은 스타일). 움직임은 코드 드로잉. Higgsfield 사용 안 함(잔액 0.03).

## 현재 IA·화면
떠 있는 캡슐 탭바 4개: 집중 / 꾸미기 / 기록 / 할 일.
- 집중: 지금 할 일 카드, 장면·소리·잠금, 시간 링(드래그 10~180분, 5분 단위), 친구·태그 칩, 시작+메모. 진행 중엔 탭바 숨김.
- 꾸미기: 장면별 6×6 풍경 배치, 보관함·도감·상점.
- 기록: 프로필 카드(칭호 10단계·다음 목표), 대결 카드, 통계·집중 달력·세션 로그, 명예의 전당.
- 할 일: 태그별 할 일 + 인박스.
- 완료 시 보상 시트(친구 1 + 물방울, 승급 축하, 공유 카드).

## 지금 있는 데이터/API
- `AppState`(단일 ChangeNotifier), `LocalStore` JSON 파일 1개. `Progress` 묶음: tags, owned, placements, drops, lockEnabled, soundId, escapeSpent, rankNickname, selectedCompanionId. 필드 추가 시 fromJson 기본값 필수.
- 경제: 완료 세션만 보상. 실집중 1분 = 물방울 1, 세션당 친구 1. 비상 탈출 = 남은 1분당 물방울 2, 보상 없음. 시작 10초 안에만 취소. 폰은 일시정지 없음.
- `FocusTitle`: 완료 누적 분 기준 10단계(0·30·150·450·1200·2400·4800·9000·15000·30000분). 비상 탈출로 내려가지 않음.
- `Companion`: 장면당 4종, 16종. 해금 = 장면별 누적 분(0·60·180·360). 이미지 `assets/mobile/companions/<id>.webp`.
- `streakDays`: 세션 endedAt 기준 계산(그만두기도 포함됨, 얼음 없음).
- 서버(Supabase, 익명 계정+닉네임): `daily_points.gained`(하루 720 상한), `ranking()` 이번 주/달/누적, `hall_of_fame` 지연 스냅샷, `duels()`, `my_invite_code()`, `accept_invite()`, `remove_friend()`. 크론 없음(첫 조회자 방식). 출시된 앱이 쓰는 RPC 시그니처 삭제 금지.
- 공유 카드(`share_plus`), 카카오 공유 SDK 연결 완료.
- 토큰: `lib/core/design_tokens.dart`, 장면 값은 `FocusScene`/`SceneStyle`에 모은다. 화면 코드 하드코딩 금지.
- 주요 파일: `lib/mobile/mobile_shell.dart`, `lib/mobile/focus/{focus_home,mobile_ring,sheets}.dart`, `lib/mobile/records/*`, `lib/mobile/scenery/*`, `lib/mobile/duel/*`, `lib/mobile/widgets/title_avatar.dart`.

## 제약
- 집중 시작까지 탭 수 증가 금지. 앱 켜고 한 번에 시작 가능.
- 앱 잠금 동작, 세션 복구, 보상 1회 확정 로직 회귀 금지. 타이머는 시계 기준.
- 잠금·휴식과 충돌 금지. 진행 중엔 다른 탭·팝업 금지(보상 연출은 완료 후).
- 벌주는 표현 금지. 연속일이 끊겨도 탓하지 않는 문구. ADHD 사용자에게 수치심 금지.
- 조작적 패턴 금지: 현금 결제 없음, 광고 없음, 가짜 희소성·압박 알림 금지.
- 리그는 서버 필요. 크론 없는 구조 유지 권장(첫 조회자 지연 정산), 익명 계정, 하루 상한 유지. 위조 방지 = 서버가 계산.
- 개인정보 처리방침 갱신 필요(리그·아바타·초대 코드).
- iOS 15 이상 추정, iPad 지원(가로 두 칸 포함), 작은 폰(SE)·큰 글자에서 넘침 금지. 동작 줄이기 대응. 화면 켜진 채 수 시간 돌 수 있어 배터리 예산 필요.
- 알림은 사용자가 켠 경우만.

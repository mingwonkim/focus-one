**5. 모션·전력**

이행: 세션·재화·보유·배치 보존. XP·칭호는 완료 기록으로 계산. 칭호 문턱 0/30/150/450/1200/2400/4800/9000/15000/30000 유지. 이행 전 날짜의 연속일은 기존 ‘중단도 인정’ 규칙 보존, 이후만 새 규칙. 얼음은 이행일 이전 소급 소비 없음. 과거 퀘스트 재지급 없음. 친구분은 companionId 있는 기록만 소급.

서버는 실제 집중·잠금 준수 증명 불가. 구 submit_score는 최초 제출·반올림 허점 존재, 새 리그 점수로 사용 금지.

‘물방울 부족 시 탈출 불가’는 무압박과 충돌. 확정 경제 유지하되 무료 비상 종료 별도 검토 권고. 개인정보 안내에 리그·아바타·삭제 반영.

## 자세한 설명

<!-- limit:4000 begin -->
Fokko는 산만해지기 쉬운 사람, 특히 ADHD인 사람을 위해 만든 집중 타이머예요.
할 일을 여러 개 늘어놓지 않고, 지금 할 일 딱 하나에만 머물게 도와요.

■ 딱 하나만
• 지금 할 일 하나를 고르고 시작 버튼만 누르면 끝
• 10분부터 180분까지, 링을 돌려 시간을 정해요
• 할 일 없이 태그만 골라 바로 시작해도 괜찮아요

■ 집중한 만큼 차올라요
• 바다는 파도가, 숲은 나무가, 밤은 별이, 카페는 아이스 아메리카노가 화면을 채워요
• 시간이 끝나면 화면이 가득 차요

■ 끝까지 가게 도와요
• 일시정지가 없어요. 시작했으면 끝까지
• 처음 10초 안에는 그만둘 수 있어요. 그 뒤엔 모아 둔 물방울을 내야 비상 탈출할 수 있어요
• 앱 잠금: 집중하는 동안 고른 앱을 잠가요. 끝나면 자동으로 풀려요

■ 성장하는 재미
• 집중할수록 레벨이 오르고, 칭호마다 색이 바뀌는 성장 지도를 따라가요
• 일일·주간 목표를 직접 정해요
• 오늘의 퀘스트와 주간 퀘스트를 채우면 상자 속 물방울을 받아요
• 연속 집중일을 쌓고, 빠진 날은 얼음으로 지켜요
• 365일 연속까지 이어지는 업적

■ 친구 모으기와 꾸미기
• 처음부터 함께하는 기본 친구 4종과, 집중할수록 만나는 친구까지 모두 36종
• 물방울로 장식을 사서 나만의 풍경을 꾸며요
• 도감에서 아직 못 만난 친구를 확인해요

■ 함께 겨뤄요 (원하는 사람만)
• 닉네임만으로 명예의 전당과 주간 리그에 참여해요. 가입은 필요 없어요
• 친구를 초대해 이번 주 집중 시간을 1:1로 겨뤄요

■ 장면과 소리
• 숲 · 밤 · 바다 · 일상 네 가지 장면
• 새소리, 시냇물, 빗소리, 풀벌레, 바람, 파도, 항구, 카페, 도서관, 기차 안, 모닥불
• 백색소음 · 갈색소음

■ 딴생각은 메모로
• 집중하다 떠오른 생각은 '딴생각 메모'에 던져 두고 다시 집중
• 메모는 나중에 할 일로 옮길 수 있어요

■ 개인정보
• 할 일과 기록은 기기 안에만 저장돼요. 명예의 전당·리그·대결에 참여하면 닉네임과 집중 시간 등이 서버에 올라가요
• 광고와 추적이 없어요

### 접근성 API 선언

Fokko는 장애인 보조 도구가 아니라 집중 앱이므로 `isAccessibilityTool`을 설정하지 않는다.

한국어: 사용자가 고른 앱을 집중 세션 동안 막기 위해 접근성 API로 지금 앞에 열린 앱의 패키지 이름만 확인합니다. 고른 앱이 열리면 Fokko 화면으로 돌아옵니다. 화면 내용은 읽지 않으며(`canRetrieveWindowContent=false`), 패키지 이름은 저장하거나 전송하지 않습니다. 세션이 끝나면 아무것도 막지 않습니다. 사용자는 앱 안의 고지 화면에서 동의한 뒤 Android 설정에서 직접 켭니다.

English: Fokko uses the Accessibility API only to read the package name of the app currently in the foreground, so it can keep the apps the user selected closed during a focus session. When a selected app opens, Fokko returns to the foreground. It does not read screen content (canRetrieveWindowContent=false), and it does not store or transmit package names. Nothing is blocked after the session ends. The user sees an in-app disclosure, agrees, and turns the service on in Android Settings.

시연 영상: `docs/v3/store-assets/android/accessibility_demo.mp4` (Play는 링크를 요구한다. YouTube 일부 공개 등으로 사용자가 올린다).

### Play 심사 메모 (English)

Fokko is a single-task focus timer. The UI is Korean. No login is needed.

App lock: Focus tab > lock icon at the top right > agree and open Settings > turn on "Fokko 집중 잠금" > return to the app > select an app > save. Start a session (default 25 minutes). Opening the selected app returns to Fokko. After the session ends, the app opens normally.

Optional ranking and league: Growth tab > League, or Records tab > Hall of Fame > Join. A random nickname is generated from a fixed word list with no free-text input. This creates an anonymous account. "나가기" (Leave) deletes the anonymous account and its server data.

Emergency exit costs droplets earned by focusing. Droplets are not purchasable. There are no ads or in-app purchases.

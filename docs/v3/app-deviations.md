# v3 설계서와 다르게 한 것

- SE 링 184 → 150: 스탯 바가 추가되어 184면 시간 숫자가 버튼에 가려짐.
- 진행 중 `딴생각 메모`는 주 버튼이 아닌 흰 보조 버튼: 바다·숲 주 버튼 색이 차오름 앞층과 같아 버튼이 사라져 보임.
- 저전력 모드 15fps 미적용: Flutter에 기본 API가 없어 플러그인이 필요. 실기기 전력 측정 후 결정.
- 스탯 바 세 번째 칸은 `오늘 N분`: 목표는 2단계에서 `N/목표분`으로 교체.
- 숲 나무는 링과 겹치지 않게 화면 양옆에만 배치.
- 사용자 피드백(11/06)으로 차오름 변경: 숲 = 연한 나무가 물들며 자라 화면을 덮음(줄 9개) / 밤 = 경계선·달 없이 화면 전체가 남색→우주 검정, 별 증가 / 일상 = 커피색 그라데이션+크레마. 바다는 그대로.
- 사용자 피드백(11/06): 집중 중 링을 남은 비율(줄어듦) → 지난 비율(차오름)으로 변경, 배경과 방향 통일. 설계서 §5 '링은 기존 남은 비율 유지'와 다름. 밤은 보라빛 해질녘에서 시작(시작이 어두워 변화가 안 보였음). 일상은 아이스 아메리카노(맑은 커피·얼음, 크레마·빨대 없음, 바다와 같은 2겹 출렁임).
- 사용자 피드백(11/06): 링 안쪽은 불투명 바탕(차오르는 색이 링과 그림 사이로 비치지 않게). 친구가 점점 선명해지는 효과는 유지(사용자 요구).
- 2단계: 목표를 올리면 바로, 낮추면 다음 기간부터(설계서는 모두 다음 기간). 첫 설정이 내일로 밀리면 고장처럼 보이고, 올리는 건 보상을 악용할 수 없음.
- 2단계: gameTimeZone 미적용. 기존 기록이 기기 시각 기준이라 키도 기기 시각. 해외 이동 시 하루가 어긋날 수 있음.
- 2단계: goalHistory·pendingRewards 미적용. 보상은 달성 순간 확정 지급하고 키로 중복만 막음. 상자 연출은 3단계.
- 2단계: 일일 '1회 완료' 퀘스트 +5는 3단계로. 일일 목표 +10·주간 목표 +30·얼음 1은 지금 지급.

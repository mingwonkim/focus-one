## 홈(집중 타이머) — 대기
- 제목 "얼음 속 친구를 깨워볼까요?" 22pt 볼드 + 보조 13pt.
- 중앙: **얼음 결정(팔각 보석) 안에 동물**, 바깥 팔각 트랙 링 + 상단 노브 → **링을 드래그해 10~180분(5분 단위)**.
- 칩 "아기 펭귄 · 탭하여 변경" → 보상 선택 시트.
- 큰 시간 "10:00" (얇은 굵기 ~64pt).
- 태그 칩 "● 공부 ⌄" → 태그 시트.
- 주 버튼 "시작" 알약(폭 ~250pt) + 링크 "❄ 나의 북극섬 보기".

## 홈 — 진행 중
- 좌상단 메뉴 대신 "● 집중 중" 칩, 제목 "얼음이 천천히 녹고 있어요 / 집중할수록 친구의 모습이 선명해져요".
- 링 노브가 진행에 따라 이동, 시간 "09:37"(세미볼드로 바뀜), 태그 칩, 하단 원형 [■ 그만두기][‖ 일시정지].

## 시트들 (하단 시트, 흰/연하늘 배경, 우상단 원형 X)
- **집중 사운드**: 끄기 / 음악(피아노·로파이 4곡) / 환경음(잔잔한 파도·섬의 빗소리). 행 카드 + 체크. 하단 "선택한 소리는 다음 집중에도 기억돼요".
- **태그**: "공부 · 이번 주 0분" 행 + "+ 새 태그 만들기". 태그 열면 할 일·이름 수정.
- **이번 집중 보상 선택**: 정보 줄 "현재 10분 · 조건에 맞는 보상만" → 3열 카드(펭귄 / 물범 🔒10시간 또는 친구 2명 / 범고래 🔒친구 7명 또는 Pro) → 상점 링크 → 선택 요약 바 → "선택 완료".

## 나의 북극섬
- 풀스크린 3D 바다 + 물결 테두리 섬. 헤더 "나의 북극섬 0/36", [눈 숨기기][✎ 편집].
- 편집: 섬 위 **아이소메트릭 6×6 격자(36칸)**, 하단 [동물|장식] 세그먼트 + 카드 인벤토리(아기 펭귄 ×1) → 카드를 칸으로 드래그. 빈 칸 길게 누르면 설원↔바다 지형 변경.
- 빈 상태 문구 "아직 아무도 살지 않는 섬이에요".

## 통계
- 연속 카드("0일" + 7칸 점선 박스), 세그먼트 일/주/월/년, 빈 상태 카드.
- "나의 집중 분석 PRO": 태그별 집중 시간 / 집중 잔디 / 골든타임 — 블러 + 자물쇠.

## 보관함 · 도감 · 상점 · 설정
- 보관함: 3칸 통계(보유/배치 중/배치 가능) + 칩(전체/동물/장식) + 정렬 + 카드 그리드.
- 도감: 진행 바 "세 종 · 12단계 중 1단계" → 종별 카드(펭귄 1/4, 4칸 실루엣 "?", 해금 조건 우측).
- 상점: 2열 카드(이글루 30 / 나무 15 / 벤치 10 / 꽃밭 10, 얼음 가격) + Pro 배너.
- 설정: Pro 카드, 내 계정(로그인 보상·백업·친구 초대), 나의 북극(오로라 Pro), 집중(알림·리마인더·사운드), 일반(언어·모션 줄이기).

## Deep Focus (모래시계)
- 전체 화면: 자물쇠 아이콘 카드 → "집중하는 동안 앱을 잠가둘까요?" → 3개 안심 문구(세션 동안만·전화/메시지 열림·그만두면 해제) → "스크린 타임 권한 허용" / "나중에 할게요". 상단 "취소".

## FocusOne에 가져올 점 / 다르게 할 점
- 가져옴: 사전 권한 안내 화면 패턴, 시트 구조(X 원형·카드 행), 진행 중 상단 크롬 숨김, 보상 선택 조건 표기, 도감 실루엣, 보관함 3칸 요약, 통계 연속 카드+세그먼트.
- 다르게(심사 4.1 대응): **탭바(떠 있는 캡슐 4개)**로 드로어 대체, 홈 맨 위에 "지금 할 일 하나" 카드 + 딴생각 메모 버튼, 링은 v2 원형 장면 링(얼음 결정 아님), 섬·얼음 대신 **장면 풍경**(숲/밤/바다)과 친구, 재화 이름 자체(예: 씨앗·별빛·물방울 중 택1), 밝은 파스텔 기본(밤 장면만 다크).
- 하지 않음: 로그인 강제 화면, 실행 직후 페이월, 광고.

## 완료 (실측 10분 세션)
- 상단 칩 "● 집중 완료", 재화 칩 0→1 즉시 반영.
- 가운데 카드 모달(흰→연하늘, 반경 ~28): "획득한 보상" 20pt + "10분 집중 완료" 11pt → 동물 이미지 ~100pt → 이름 → 재화 행 "🧊 집중 얼음 1개"(연하늘 카드) → "확인" 알약 → "광고 보고 얼음 2배"(텍스트 버튼).
- 재화 비율: 10분 = 1개 (분당 0.1).
- FocusOne: 같은 정보 순서는 업계 표준(Finch·Ahead도 동일). 광고 줄 없음. 모달 대신 장면 위 하단 시트 + 친구 팝 애니메이션·햅틱으로 다르게.

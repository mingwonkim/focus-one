**2. 컴포넌트·상태**

링은 미니 지름88/두께12/안쪽 여백14, 확장160/24/28. 외곽 기준 여백, 일러스트 원60/104. 12시부터 남은 비율1→0, 둥근 끝. 중앙 글자·글자용 베일·링 글로우 제거. SceneDialPainter 유지. 60px 원에서도 달토끼 귀·몸통이 구별되도록 확대. 바다 모랫바닥은 청록 틴트. 외부 장식 제거.

카드: 좌우12＋칩32＋간격12＋텍스트240＋간격12＋체크48＝368. 제목14/600·행높이20, “집중 n회”12/400·행높이16. 체크 원24, 선1.5. 선택은 accent 테두리2, 완료는 취소선·채운 체크와 “완료 n” 구분줄. 행 클릭은 기존 작업 선택/타이머 리셋. 삭제는 우클릭·Shift+F10 메뉴.

현재 체크는 `completeCurrentTask`. 비선택 체크는 타이머·선택을 보존하는 `completeTask(id)` 추가. `selectTask` 경유 금지.

세션 메뉴는5/15/25/45분. 대기·일시정지에 변경, 남은 시간 초기화. 사운드는240×64 팝오버: on/off40＋간격8＋볼륨168＋좌우12. 장면은 숲→밤→바다 순환.

소형 타이머는 좌우12, 링40·두께6→텍스트128→리셋32·알약80·완료32, 간격8. 시간20/700, 상태12. 인박스 행64: 텍스트2줄·승격/삭제32. 차단은 사용 스위치→강제 종료 스위치→앱 추가/삭제→사이트 키워드 추가/삭제 순서. 긴 항목은 줄바꿈.

[WCAG 대비식](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)으로 계산: accent의 바탕/카드 대비는 숲5.86/6.40, 밤9.71/8.23, 바다5.90/6.39:1. 텍스트3단 최솟값은5.13/6.60/5.06:1. 알약 글자≥17.31:1, 진행/트랙≥3.04:1. 작은 글자에 투명도 적용 금지.

시스템 UI 글꼴·한글 폴백. 제목20/700, 작업14/600, 본문14/400, 버튼14/600, 보조12/400. 시간은 확장40/700·미니20/700, tabularFigures. 자간0. 반경은 창24·카드/입력16·알약9999. 목록 그림자는 #000000 6%, blur8/offset(0,2); 밤은 없음. 창 외부 그림자 없음.

design_tokens.dart의 SceneStyle에 색·타이포, AppSpacing에 간격·치수, AppRadius에 반경 반영. AppDuration·AppShadow 수정. 하드코딩 금지.

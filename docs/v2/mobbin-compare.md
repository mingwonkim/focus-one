# Tiimo 레퍼런스 vs FocusOne v2 (확장 패널)

| 항목 | Tiimo Focus | v2 | 판정 |
|---|---|---|---|
| 위계 | 제목 → 시간범위 → 링 → 큰 숫자 → 컨트롤 | 헤더 → 현재 작업·세션 칩 → 링 → 큰 숫자 → 컨트롤 | 비슷함 |
| 링 | 굵은 단색, round cap, 옅은 트랙 | 동일 (두께 = 지름 15%) | 같음 |
| 링 안 | 모래시계 일러스트 | 장면 일러스트(숲/달토끼/고래) | 다름(의도) |
| 주 버튼 | 검은 알약 ⏸ | 검은 알약 아이콘+라벨 (밤은 회색) | 같음 |
| 보조 | +1 min 텍스트 | 리셋·완료 원형 버튼 | 다름(기존 기능 유지) |
| 리스트 | 흰 카드, 왼쪽 아이콘 칩, 오른쪽 원형 체크, DONE 섹션 | 동일 구조, "완료 n" 섹션 | 같음 |
| 바탕 | 거의 흰색 | 장면 파스텔 틴트 / 밤 다크 | 비슷함 |
